# 열매담 FRUIDAM 첫 출시 기획

최신 결정 추가(2026-11-06): 운영자는 입점 농가의 신청 내용과 등록 상품을 조회·수정한다. 같은 공급처의 기존 상품을 운영자가 수정하면 판매 상태를 유지하며, 신규 상품·농가 직접 수정·공급처 변경·공개 상품의 사진 전체 삭제는 검수 대상으로 처리한다. 옵션의 ‘등급(당도)’은 특급/상/중/하 중 선택하며 상품 사진 오른쪽 위에 등록된 등급을 붉은색 배지로 표시한다. ‘열매담 이야기’는 산지 농가의 정성 → 온라인 연결 → 소비자 식탁이라는 브랜드 메시지를 전달한다. 기존 녹색과 열매담 로고로 만든 동일한 공통 표지를 공급상품 연동 상세페이지 맨 앞에 고정하고, JPG/PNG 긴 이미지와 HTML에도 포함한다. 표지는 편집·삭제·숨김·이동·AI 문구 수정 대상에서 제외한다. 기존 단독 제작 프로젝트는 유지한다.

최신 결정 정리(2026-11-04): 상품 등록의 상품 태그 입력은 삭제하고 품종은 분류 옆에 배치한다. 과세 여부·출고형태·택배사·생산연도·보관구분/안내·제주/도서산간 추가 배송비·최대 10장 사진과 대표 사진 선택을 제공한다. 옵션은 등급·중량·크기/규격·과수/개수·공급가·재고를 분리 입력하며 옵션명을 자동 구성하거나 직접 지정한다. 입력값은 상품 상세와 상세페이지 제작 자료에 연결한다. 과세 여부·생산연도·보관 정보는 임의 추정하지 않는다. 상품 상세의 원본 사진 ZIP 다운로드와 완성 상세페이지 다운로드는 구분한다. 지역별 추가 배송비는 발주 시 선택한 지역에 따라 주문 1건당 한 번 합산하며 엑셀 양식에도 배송지역을 포함한다.

최근 합의는 이전 작업 이력보다 우선한다. 출고형태 기본값은 산지출고, 기본 배송비는 무료배송으로 고정하고 추가 운임·공급가·수량은 숫자 입력·천 단위 쉼표를 지원한다. 공급상품에서 제작할 때 상품명·사진·옵션과 특징 원문을 첫 입력 단계로 가져오며 특징에 원산지·공급처·배송 등의 부가 정보를 덧붙이지 않는다. 구성안에서 AI가 후킹·핵심 포인트를 다듬고 원본과 연출 사진을 혼합한다. 완성 상세페이지는 분할 ZIP 대신 전체가 이어진 JPG/PNG 파일 1개로 다운로드한다. 구현 상태와 제한은 [현재 진행 상황](STATUS.md)을 따른다.

확정일: 2026-11-02 (한국 시간)

이 문서는 사용자와의 기획 인터뷰에서 합의한 제품 범위다. 운영 서비스의 기능 구현·결제·배포 완료를 의미하지 않는다.

## 목적과 대상

과일을 판매하려는 셀러에게 상세페이지 제작과 위탁상품 공급을 함께 제공한다. 승인된 농가·직매장이 상품을 공급하고 소비자에게 직접 배송한다. 셀러는 자신의 스마트스토어 등 외부 판매 채널에서 판매한다. 첫 출시는 국내 판매·국내 배송을 대상으로 한다.

서비스: https://fruidam-studio.vercel.app/

관련 저장소: https://github.com/20wodud-alt/fruidam-studio

## 이용자와 권한

- 셀러: 이메일 가입 후 별도 승인 없이 무료 체험 가능. 유료 이용 권한에 따라 제작·다운로드·발주 가능.
- 공급처: 농가·직매장이 입점 신청. 운영자가 위탁배송과 문제 대응 가능 여부를 확인해 승인.
- 운영자: 공급처 승인, 상품 검수, 분쟁 중재, 정산 확인 및 지급 완료 기록.
- 단체: 관리자 포함 총 5명(관리자 1명, 구성원 4명). 제작 건수 공유. 구성원은 자신의 주문·배송지·문의만 확인하고 관리자는 팀 전체를 관리.

## 상품과 상세페이지

- 공급처가 사진, 원산지, 품종, 중량, 크기·등급, 구성, 공급가, 배송비, 출고 일정 등을 입력. 운영자 검수 후 공개.
- 초기에는 운영자가 공급처를 대신해 상품 등록 가능.
- 같은 상품의 중량·크기·등급은 옵션으로 묶어 상세페이지 1건으로 제작. 옵션별 공급가와 재고는 별도 관리.
- 공급처나 품종이 다르면 별도 상품.
- 공급처는 제공 자료를 셀러 판매 채널에서 사용할 수 있도록 동의.
- 실제 상품 사진을 반드시 포함. AI 이미지는 배경·연출용으로 추가하고 연출 이미지임을 표시.
- 중량·등급·원산지·인증 등 사실 정보는 공급처 등록값 사용. AI가 상품 외관·품질을 임의 변경하지 않도록 구성.
- 모바일에서 읽기 좋은 세로형 상세페이지. 다운로드 전 문구·구성 수정 가능.
- 결과물: 전체가 이어진 긴 JPG/PNG 이미지 파일 1개, 별도 보관용 HTML, 편집 가능한 상품명·판매 문구. 완성 상세페이지를 여러 이미지로 나눈 ZIP은 제공하지 않는다.
- 판매 채널 자동 게시와 주문 자동 수집 연동은 후속 범위.

## 요금과 제작 건수

| 구분 | 가격 | 제공량 |
| --- | --- | --- |
| 무료 체험 | 0원 | 가입 후 3일간 상품 1개 제작·미리보기 |
| 건별 결제 | 9,900원 | 1건 |
| 기본 구독 | 월 39,000원 | 월 5건 |
| 성수기 플랜 | 월 79,000원 | 월 10건 |
| 단체 플랜 | 월 199,000원부터 | 월 25건부터, 기본 총 5명 |

- 가입 전 상품 구성과 샘플 공개. 공급가 확인, 완성본 다운로드, 발주는 유료 이용 후 제공.
- 무료 체험은 자동 결제하지 않으며 다운로드·발주 불가.
- 무료 체험을 포함해 상세페이지 1건당 AI 이미지 생성 최대 3회. 실제 비용 확인 후 조정.
- 미리보기·직접 문구 수정에는 제작 건수 차감 없음. 완성본 첫 다운로드 때 1건 차감.
- 동일 완성본 재다운로드 무료. 다른 상품 또는 디자인으로 새 완성본 제작 시 추가 1건.
- 매월 결제일에 건수 갱신. 미사용 월 제공 건수 이월 없음. 부족하면 건당 9,900원 추가 구매.
- 월 구독 자동 갱신. 해지하면 다음 결제부터 중단하고 결제한 기간까지 이용.
- 구독 종료 후에도 기존 주문 배송 조회와 문제 접수 유지.
- 단체 기본 인원·건수 초과는 별도 견적.

## 발주 권한

- 구독 기간 중에는 전체 공급 상품 발주 가능.
- 건별 고객은 구매한 상세페이지의 상품을 횟수 제한 없이 발주 가능.
- 유료 제작 건수를 차감해 완성본을 받은 상품은 구독 종료 후에도 계속 발주 가능.
- 공급 중단 상품은 발주 불가.

## 주문과 배송

1. 셀러가 외부 판매 채널에서 소비자 주문을 받음.
2. 우리 사이트에 주문 직접 입력 또는 엑셀 업로드.
3. 최신 배송비 포함 공급금액을 확인하고 결제하면 발주 확정.
4. 직매장이 주문 확인 후 직접 배송하고 송장번호 등록.
5. 배송 완료 및 문제 처리 내역 관리.

- 여러 주문 일괄 등록·결제 가능. 시스템은 공급처별로 발주 분리.
- 공급처는 자기 주문만 확인.
- 배송비 포함 금액은 상품·배송 건별 계산. 첫 버전 합배송 할인 없음.
- 상태: 결제 완료 → 출고 준비 → 배송 중 → 배송 완료.
- 결제 완료 상태에서는 셀러 즉시 취소. 출고 준비 이후에는 공급처 확인을 거쳐 취소 가능 여부 결정.
- 직매장이 출고 가능 수량, 마감 시간, 출고 예정일 관리. 결제 시 수량 차감.
- 품절·판매 중단을 셀러에게 알리고 공급 불가 주문은 취소·환불.
- 공급가·구성·배송 조건 변경 시 상품을 제작했거나 발주한 셀러에게 알림.
- 신규 발주는 최신 공급가 적용. 기존 결제 주문은 결제 당시 금액 유지.

## 고객 응대와 분쟁

- 소비자 문의는 셀러가 접수.
- 셀러는 주문에 문제 유형, 설명, 사진, 희망 처리(재배송 또는 환불)를 등록.
- 직매장이 상품·배송 문제를 확인해 처리. 의견 불일치 시 운영자 중재.
- 처리 이력과 환불·재배송 상태를 해당 주문에 기록.

## 수수료와 공급처 정산

- 공급처별 약정 수수료율 설정. 수수료 산정 기준은 배송비 포함 총 공급금액.
- 취소·환불 금액은 수수료 계산에서 제외.
- 배송 완료 주문을 모아 주 1회 정산. 분쟁 중인 주문은 해결 후 정산.
- 시스템이 결제금액·수수료·환불·최종 정산액 계산.
- 운영자가 내역 확인 후 송금하고 지급 완료 기록. 공급처는 본인 정산 내역 확인.
- 은행 자동 송금 연동은 후속 범위.

## 알림

- 사이트 내 알림과 이메일 제공.
- 주요 알림은 카카오 알림톡 우선, 전달 실패 시 문자로 대체.
- 공급처: 신규 발주, 취소 요청, 문제 접수 등.
- 셀러: 주문·배송·문제 처리 상태, 공급 조건 변경 등.
- 동일 알림을 카카오톡과 문자로 중복 발송하지 않음.

## 첫 출시 검증

- 공급처 2~3곳, 상품 약 10개로 시작.
- 유료 셀러 5명 확보.
- 상세페이지 다운로드 10건.
- 위탁 주문 배송 완료 10건.
- 공급처 정산 1회 완료.
- 제작 비용, 셀러 재이용, 배송·품질 문제를 확인해 확대 여부 판단.

## 기존 서비스 확인 결과와 개발 순서

브라우저에서 작업 목록, 기존 상세페이지 편집 화면, 텍스트·사진·레이어 등 편집 도구와 다운로드 버튼을 확인했다. 실제 신규 AI 생성·결제·다운로드 실행은 검증하지 않았다. 화면에는 로컬 작업실 안내가 있으나 저장소에는 Supabase 저장 관련 코드와 마이그레이션도 있으므로 실제 배포의 저장 방식을 소스와 설정으로 추가 확인해야 한다. 저장소 package.json 기준 Next.js·React·TypeScript 프로젝트다.

권장 개발 순서:

1. 기존 편집기·저장 구조 확인, 회원·역할·팀·데이터 접근 권한 구축.
2. 공급처 입점 승인, 상품·옵션·재고 등록과 검수, 상품 선택에서 기존 편집기로 연결.
3. 체험·요금제·결제·제작 건수·상품별 발주 권한 구현.
4. 주문 엑셀·결제·공급처 발주·송장·취소·문제 접수 구현.
5. 수수료·주간 정산·이메일·알림톡·문자 구현 및 전체 흐름 검증.

## 별도 확인이 필요한 운영 설정

아래 항목은 인터뷰에서 수치나 제공 업체가 확정되지 않았다. 임의로 확정하지 않는다.

- 공급처별 실제 수수료율과 정산 요일.
- 결제 대행사, 이메일·알림톡·문자 제공 업체 및 운영 계정.
- 구독 변경·중도 환불 세부 기준, 별도 구매 건수의 유효기간, 가격의 부가세 포함 여부.
- 지역별 배송 가능 범위와 추가 운임, 재배송·환불의 세부 판정 기준.
- 단체 플랜 추가 인원·추가 건수 견적.
- 현재 배포와 저장소의 버전 일치 여부 및 실제 Supabase 연결 상태.
