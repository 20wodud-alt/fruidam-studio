## 확정한 서비스와 운영

- 전국 산지 농가·직매장과 과일 판매 셀러를 연결한다. 셀러가 상세페이지를 만들어 외부 판매 채널에서 판매하고, 입점 공급처가 소비자에게 직접 포장·배송한다.
- 열매담은 공급처와 정한 마진/수수료, 셀러의 구독·건별 제작 요금을 수익 모델로 한다. 정산 수수료는 지역 추가 배송비를 포함한 총 공급금액 기준이다.
- 요금은 무료 체험 0원, 건별 9,900원/1건, 기본 월 39,000원/5건, 성수기 월 79,000원/10건, 단체 월 199,000원부터/25건부터다. 단체는 관리자 1명이 결제하고 기본 총 5명이 공유하는 계획이다.
- 무료 체험은 가입 후 3일, 상품 1개 제작·미리보기, 자동 결제 없음. 무료 체험 포함 프로젝트당 AI 이미지 생성 최대 3회이며 실제 비용 확인 후 조정한다.
- 건별 고객도 해당 유료 제작 상품의 위탁 발주를 이용하는 방향이다. 실제 결제·구독 연결은 아직 남아 있다.
- 공급처 입점과 상품 공개는 운영자 승인·검수를 거친다. 승인 취소 시 신규 등록·발주와 판매를 제한하고 기존 주문·정산 기록은 보존한다.
- 운영자 표시는 열매담, 운영 이메일은 `20wodud@gmail.com`. 준우농원은 입점자 `23wodud@gmail.com`, 새재농원은 `21wodud@gmail.com`이다. 입점 승인과 Auth 이메일 인증은 별도이며 인증을 우회하지 않는다. 개별 계정 인증 상태는 11월 3일 확인 기록을 참고하며 이번에는 재조회하지 않았다.
- 문자·카카오톡·업무 이메일 알림은 요청 범위이나 서비스 업체 연결은 아직 없다. 사이트 내 알림 및 Auth 가입 인증 메일과 구분한다.

## 최근 구현과 최신 화면 결정

- 공통 헤더·로고·메뉴 위치를 통일하고 고정했다. 로고는 이전 대비 30% 축소, 클릭 시 홈 이동. 무료 시작 버튼은 비회원 홈에서만 표시한다. 상단 초록 띠에는 상호명과 로그인/로그아웃을 표시한다.
- 열매담 이야기 페이지는 산지·지역 상생·정직한 가격·신선한 배송의 브랜드 방향으로 구성했다. 실제 상품 사진과 생성 연출 이미지를 구분한다.
- 상품 등록은 최대 10장 사진과 옵션·보관·배송 정보를 지원한다. 원산지는 전국 시·도→시·군·구 선택. 상품 태그는 삭제, 품종은 분류 옆으로 이동했다.
- 기본 배송비는 무료배송, 출고형태는 산지출고 기본 선택. 제주·도서산간 추가 운임, 공급가·출고 수량은 숫자 입력·쉼표 표시·클릭 전체 선택을 지원한다. 상품 등록 창은 배경 클릭·Esc로 닫히지 않고 X 또는 저장 성공 시 닫힌다.
- 상품 상세의 ‘이 상품으로 상세페이지 만들기’는 상품명·특징 원문·사진·옵션을 제작 첫 단계에 채운다. 특징에는 원산지·공급처·품종·보관·배송 등의 부가 정보를 자동 첨부하지 않는다. 불러오기만으로 프로젝트·무료 체험을 소비하지 않는다.
- 구성안 생성에 Gemini 카피 작성을 연결해 후킹·핵심 포인트를 다듬는다. 대표·옵션 원본은 유지하고 산지·과육 접사·식탁 연출의 구도를 나눈다. 기존 작업은 ‘과일 구성 다듬기’로 적용하며 수정 전 비공개 백업을 남긴다. Gemini 미연결 시 기본 카피와 연결 필요를 안내한다.
- AI 참고 사진 배열의 순번이 너비 0으로 전달되던 버그를 수정했다. 원본 사진 처리 후 실제 외부 요청 직전에만 시도 한도를 예약하며 사전 처리 실패는 차감하지 않는다. 해당 감귤 프로젝트에서 사전 실패로 차감됐던 2회를 백업 후 복구했다. 실제 외부 요청 실패는 시도에 포함하고 자동 재시도하지 않는다.
- 완성 상세페이지는 분할 ZIP 대신 긴 JPG/PNG 파일 1개로 저장한다. 스마트스토어 848px·쿠팡 프리셋 780px 너비, 숨긴 섹션 제외, 사진·글꼴·서식 유지. 원본 상품 사진 묶음 ZIP과 보관용 HTML은 별도다. 출력 높이 32,760px 초과 시 임의 분할·잘림 없이 오류를 안내한다.
