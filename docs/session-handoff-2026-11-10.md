# 열매담 공개·승인 회원 접근 정책

저장 기준: 2026-11-10, 한국 시간. 이전의 사이트 전체 비공개 및 셀러 승인 불필요 설명보다 이 결정이 우선한다.

## 사용자 결정과 구현

| 대상 | 기본 소개·상품 목록 | 상품 상세·공급가·요금 금액 | 스튜디오·생성·다운로드 |
| --- | --- | --- | --- |
| 비회원 | 공개 | 로그인·승인 안내 | 로그인 안내 및 API 차단 |
| 이메일 인증 후 로그인, 승인 대기 | 공개 | 승인 대기 안내 | 승인 대기 안내 및 API 차단 |
| 승인된 셀러·공급처 | 공개 | 확인 가능 | 계정별 작업·체험·유료 권한과 기존 역할 조건에 따라 이용 |
| 운영자 | 공개 | 확인 가능 | 기존 관리 권한 유지 |

- 공개 상품은 상품명·분류·공급처 표시 이름·대표 사진만 전달한다. 서버 응답의 허용 필드 목록으로 상세 특징·옵션·가격·재고·갤러리·지역 운임 등을 제거한다. 승인 전 주문·구매 금액도 반환하지 않는다.
- 상품 카드 클릭 시 비회원은 로그인, 대기 회원은 승인 안내를 받는다. 요금제의 금액도 비회원·대기 회원에게 표시하지 않는다.
- 운영자 화면에 ‘셀러 회원 승인’을 추가했다. 인증 후 로그인으로 등록된 셀러의 이름·이메일을 확인해 승인하거나 승인 취소한다. 가입 metadata나 요청 본문으로 스스로 승인·운영자 역할을 얻을 수 없다. 기존 대기 셀러를 자동 승인하지 않는다.
- 공급처는 기존 입점 승인과 수수료 관리로 처리한다. 이메일 인증·회원 승인·상품 검수·유료 발주/다운로드 권한은 별도이며 이번 작업이 이용권·결제 완료를 만들지 않는다. 체험/요금 정책은 유지한다.
- `withApiAccess`가 스튜디오·업로드·사진·AI·가져오기·설정·제작 원본·내보내기 API의 입력 처리와 외부 호출 전에 로그인/승인을 확인한다. 설정 변경은 운영자만 가능하다. `studioAccess`에서도 승인과 계정별 범위를 재검사한다. 승인 취소는 기존 로그인 세션에도 반영된다.
- `/studio` 서버 레이아웃은 승인 전 작업 화면 대신 안내를 렌더링한다. 공개된 승인 상품의 대표 사진만 익명 자산 요청을 허용한다. 갤러리와 스튜디오 자산은 승인 회원만 읽으며 자산 응답은 no-store로 처리한다.

## 검증

- 프로덕션 빌드·타입 검사.
- 확장한 `tests/commerce-integration.mjs`: 실제 Supabase Auth 임시 계정으로 비회원/대기 회원의 19개 API 진입점 차단, 셀프 승인 차단, 운영자 승인·취소·재승인, 로그인 중 취소 반영, 승인 셀러의 설정 변경 거부, 공개 응답에서 상세/가격 제거, 공개 대표 사진과 비공개 갤러리 분리 및 기존 계정별 작업·검수·발주·다운로드 흐름을 검사한다. 임시 계정·상품·사진·프로젝트를 정리한다.
- 기존 회원 관리 및 브랜드 표지 검사 통과. 브라우저에서 비회원 상품 클릭 → 로그인, 스튜디오 로그인 안내, 대기 화면, 승인 회원의 상세·가격 확인, 운영자 셀러 승인 버튼/상태 변경, 비회원 요금 금액 숨김을 확인했다. 브라우저의 승인 상태 검사는 fixture 응답을 사용했다.
- 로컬 검증 서버는 `FRUIDAM_AI_FIXTURE=1` 및 `tests/mock-gemini.cjs`로 실제 AI 호출을 막았다. 실제 메일·결제·은행 송금 및 운영 회원의 승인 상태는 변경하지 않았다.

## 운영 공개 순서

1. 보호 상태에서 위 기능 코드를 배포하고 Ready를 확인한다.
2. 기존 Vercel `ssoProtection.deploymentType=all`을 `prod_deployment_urls_and_all_previews`로 변경한다. [Vercel 공식 인증 문서](https://vercel.com/docs/deployment-protection/methods-to-protect-deployments/vercel-authentication)의 운영 도메인 공개·배포/미리보기 보호 범위를 따른다.
3. 쿠키 없는 요청으로 운영 홈·이야기·상품 목록을 확인하고 스튜디오 API 차단·상품 가격/상세 미전송을 재확인한다. 과거 생성 배포 주소도 계속 보호되는지 확인한다.

배포와 공개 설정의 최종 확인 결과는 작업 완료 후 아래에 기록한다. 기존 운영 DB·회원·상품·사진·프로젝트는 보존한다.
