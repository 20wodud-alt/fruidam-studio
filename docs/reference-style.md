# 과일 에디토리얼 참고 스타일

사용자가 제공한 `01.jpg`(850×16034)를 로컬에서 확대 확인하고 추출한 디자인 방향입니다. 모델 재학습이나 판매 실적 검증을 수행한 것이 아닙니다. 원본 파일을 매 요청에 재전송하지 않고 짧은 지침을 사용합니다.

- 큰 제품 정물컷 → 여백 있는 메시지 → 손으로 즐기는 장면 → 산지 → 체크포인트와 접사 → 활용 → 옵션의 리듬을 참고합니다.
- 제목은 짧고 굵게 1~2줄, 핵심은 마지막 줄에 두고 밑줄로 강조합니다. 서브는 근거를 설명하는 2~3줄입니다.
- 작은 테두리 배지로 단락을 나누고 흰 바탕을 유지합니다. 강조 색상은 프로젝트 테마를 따릅니다.
- 이미지 구도는 원물 전경·매크로·항공 뷰·현장·일상 컷으로 바꿉니다. 자연광과 절제한 식기·천·원목 소품을 참고하고 실제 상품의 색·품종·형태를 우선합니다.
- 농작업 인물은 가상의 한국인 성인 농부를 기본으로 합니다. 계절에 맞는 긴팔 작업복·조끼·작업 바지·햇빛 가림 모자·장갑·작업화 중 실제 작업에 필요한 복장을 선택합니다. 광고 포즈보다 수확·검수·선별에 집중한 모습을 사용하고, 수입산은 국내 재배 장면 대신 중립적인 선별 현장 등으로 연출합니다.
- 타사 문구, 브랜드, 사진, 포장, 생산자 신원, 산지·재배·후숙·세척·당도 주장을 옮기지 않습니다. 실제 상품 자료에 있는 사실만 카피에 사용합니다.
- 사용자가 삭제 요청한 추천 대상 및 배송·교환 안내 섹션은 추가하지 않습니다.

새 과일 구성안 생성 시 편집 가능한 섹션 서식에 적용합니다. 기존 작업의 서식은 다시 생성하지 않습니다. HTML/PNG 내보내기에도 같은 스타일을 포함합니다.
