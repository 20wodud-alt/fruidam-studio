## 확정한 서비스 방향

과일을 팔고 싶은 셀러에게 상세페이지 제작과 위탁상품 공급을 함께 제공한다. 셀러는 자신의 외부 판매 채널에서 판매하고, 농가·직매장은 승인·상품 검수를 거쳐 공급하며 소비자에게 직접 배송한다.

- 수익: 공급처별 약정 수수료와 셀러 구독·건별 제작 요금.
- 수수료 기준: 배송비 포함 총 공급금액.
- 체험: 가입 후 3일간 상품 1개 미리보기, AI 이미지 생성 3회, 자동 결제 없음.
- 요금: 건별 9,900원/1건, 기본 월 39,000원/5건, 성수기 월 79,000원/10건, 단체 월 199,000원부터/25건부터·총 5명.
- 다운로드: 완성본 첫 다운로드 때 1건 차감, 같은 완성본 재다운로드 무료. 월 제공 건수 이월 없음. 추가 제작 건당 9,900원.
- 발주: 구독 중 전체 공급상품, 건별 구매·유료 제작 완료 상품은 구독 없이도 발주 가능.
- 배송: 공급처 직접 배송, 공급처별 발주 분리. 셀러가 소비자 문의를 접수하고 공급처가 상품·배송 문제를 처리한다.
- 정산: 배송 완료·분쟁 없는 주문을 주 1회 정산. 운영자가 실제 송금한 뒤 지급 완료를 기록한다.
- 이미지: 실사 과일 사진 사용. AI 연출은 실제 상품 사진과 함께 사용하고 연출 표시를 한다.
- 브랜드: 기존 붓글씨 `열매담 FRUIDAM` 로고 사용. 모든 페이지의 로고 클릭은 `/`로 이동한다.

## 구현·배포한 기능

- 홈, 공급상품 검색·분류·상세, 요금제, 회원가입·로그인.
- `/about` 열매담 이야기: 전국 산지·농가·직매장과 셀러의 연결, 지역 상생·정직한 가격, 상세페이지 자동 생성부터 산지 직배송까지의 여정. 신규 AI 수확 브랜드 이미지와 선형 아이콘·모바일 화면, 상단 메뉴·푸터 링크와 입점·공급상품 버튼.
- 셀러·공급처·운영자 대시보드.
- 운영자·입점 알림 수신 주소는 사용자 지정 `20wodud@gmail.com`. 인증된 동일 계정의 관리자 프로필을 확인했고 Production 환경에 지정했다. 입점 관리 화면에서 주소를 확인할 수 있다. 자동 이메일 발송은 미연결이다.
- 운영자 표시 이름은 열매담. 준우농원은 `23wodud@gmail.com`을 사용하는 별도 입점 프로필로 분리했고 기존 상품 1개를 이관했다. 해당 이메일 가입·인증 시 입점 계정이 연결된다. 입점 카드 오른쪽의 승인 취소는 신규 등록·발주와 판매 상품을 중단하고 기존 주문·정산은 보존한다.
- 승인·수수료 저장 성공 시 버튼은 녹색 체크·저장 완료로 표시하며 수수료 재수정 시 초기화한다. 오른쪽 입점 승인 배지는 녹색 채움·흰색 체크, 대기는 회색으로 구분한다. 실패 응답은 완료로 표시하지 않는다.
- 공급처 승인, 상품·옵션·사진·재고 등록, 상품 검수·승인·중단, 공급처 수수료율 설정.
- 운영자의 상품 관리 화면에서 직접 등록·수정 및 승인 공급처 대리 등록. 빈 목록의 첫 상품 등록 버튼, 공급처 선택, 양식 내 오류 표시. 공급처의 기존 입점 승인과 일반 셀러 등록 제한은 유지한다.
- 상품 등록 확장: 최대 10장 사진·대표 선택, 품종·과세 여부·생산연도·보관 정보·출고형태·택배사·지역별 추가 운임, 옵션별 등급·중량·규격·과수. 상세 갤러리·정보표·사진 ZIP 및 제작 자료 연결. 직접·엑셀 발주의 배송지역에 따른 추가 운임 합산.
- 상품 태그 입력 삭제·품종은 상품 분류 옆으로 이동. 출고형태는 산지출고 기본 선택(센터출고 선택 가능), 기본 배송비는 무료배송으로 고정. 지역 운임·옵션 공급가·수량은 숫자만 입력하며 천 단위 쉼표 표시와 클릭 시 전체 선택을 지원한다. 기존 상품에는 수정 저장 시 적용한다.
- 상품 등록·수정 창은 배경 클릭과 Esc로 닫히지 않으며 X 버튼으로 닫는다. 성공적으로 저장하면 기존처럼 창을 닫는다.
- 원산지는 전국 시·도 → 시·군·구 선택으로 등록한다. 상위 지역 변경 시 하위 선택을 초기화하고 기존 상품의 원산지는 선택을 변경하기 전까지 보존한다. 출처와 갱신 기준은 [지역 목록 기록](korea-regions.md)을 참고한다.
- 개인별 상세페이지 작업 분리, 공급상품에서 편집기 연결, 체험·다운로드·AI 이미지 생성 제한.
- 직접·엑셀 발주 등록, 공급가·수량·권한 검증. 엑셀은 최대 200건/2MB, 오류가 있으면 전체 등록 중단.
- 주문·송장·배송 상태, 문제 접수와 답변, 사이트 내 알림, 정산 지급 기록.
- 사과·감귤·청포도·제주 과수원 실사 사진과 기존 샘플 이미지 경로 호환.
- 헤더·푸터·스튜디오의 기존 로고 통일. 스튜디오 로고는 편집 내용 저장 후 홈으로 이동.
- 로고는 이전 크기의 70%로 표시. 상세페이지 스튜디오 링크를 포함한 서비스 상단 메뉴와 스튜디오 작업 헤더는 스크롤 시 고정된다. 모바일 펼침 메뉴는 고정 헤더 하단에 이어진다.
- 홈과 스튜디오가 동일한 `ServiceHeader`를 사용한다. 안내 띠·로고·메뉴 위치를 통일하고 스튜디오 작업 도구는 그 아래에 배치한다. 메뉴 이동 시 수정 중인 프로젝트를 먼저 저장하며 편집 영역과 모바일 메뉴 높이를 조정했다.
- 상단 ‘무료로 시작하기’ 버튼은 비회원의 홈에서만 표시하며 다른 페이지에서는 숨긴다. 로그인·회원 공간 버튼은 유지한다.
- 스튜디오 작업 목록의 My workspace 카드와 본문 경로 표시를 삭제하고 사이드 메뉴·본문 상단 여백을 정렬했다.

## 남은 작업

사용자는 결제사·업무 알림 업체 계정이 아직 없어 화면·주문 기능부터 먼저 배포하기로 했다.

- 실제 결제, 건별 이용권 지급, 자동 구독·갱신·해지·환불, 결제 승인 후 재고 차감 연결.
- 업무 이메일·카카오 알림톡·문자 발송. 현재 가입 인증 이메일과 사이트 내 알림은 별도 기능이다.
- 단체 계정 초대·5명 공유와 제작 건수 공유.
- 재배송·환불·분쟁 종결의 전체 운영 흐름.
- 실제 공급처·상품 입점과 검수.
- 구독 변경·환불·추가 구매 유효기간·부가세·지역 운임·정산 요일 등 운영 세부 기준.
- 외부 고객 공개를 위한 legacy 비회원 studio/API 접근 전환. 기존 Vercel 인증 보호는 유지한다.

현재 발주는 결제 대기로만 저장하며 실제 결제·출고·문자 발송·은행 송금을 완료한 것처럼 처리하지 않는다. 예시 상품은 실제 발주할 수 없다.

## 검증과 보존

관련 변경 당시 프로덕션 빌드·타입 검사, 기존 저장소/이미지 처리 검사, 임시 계정 기반 통합 검사를 통과했다. 실사 이미지는 브라우저에서 디코딩과 데스크톱·모바일 표시를 확인했다. 로고는 전체 8개 경로의 링크를 확인했고, 상품 목록·스튜디오에서 홈 이동을 검증했다. 운영 배포의 스튜디오에서도 로고 클릭 후 실제 홈 이동을 확인했다.

기존 프로젝트·사진·서버 비밀키는 원래 저장소와 서버 설정에 유지한다. GitHub에 비밀키를 포함하지 않는다. 임시 검증 계정과 테스트 데이터는 정리했다. 실행 중이던 로컬 확인 서버는 종료했다.

앞서 저장 요청에 따라 상위 작업 폴더의 `열매담-작업기록-2026-11-03.md`와 `fruidam-backup-2026-11-03.zip`도 최신 문서·추적 파일 기준으로 갱신한다. ZIP은 Git에서 추적하는 코드·문서의 스냅샷이며 운영 DB와 서버 환경변수 백업은 별도다.
