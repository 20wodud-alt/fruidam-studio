# 상품 원산지 지역 목록

상품 등록·수정의 원산지는 시·도 → 시·군·구 순으로 선택한다. 지역 변경 시 하위 지역을 초기화하며 상세 지역 미지정도 허용한다. 저장 형식은 기존 `origin` 문자열을 유지한다. 기존 원산지는 지역 약칭을 인식하더라도 사용자가 선택을 변경하기 전에는 원문 그대로 보존한다. 인식되지 않는 기존 값도 유지할 수 있다.

## 자료 출처

- 행정표준코드관리시스템 [법정동 코드 조회](https://www.code.go.kr/stdcode/regCodeL.do)의 ‘법정동 코드 전체자료’ ZIP.
- 다운로드: `https://www.code.go.kr/etc/codeFullDown.do`
- 확인·다운로드 일자: 2026-11-03.
- ZIP 내부 CP949 TSV의 `폐지여부=존재` 행만 사용한다. 지역명이 한 단어인 행을 시·도로, 해당 시·도 아래 법정동 코드가 `00000`으로 끝나는 행을 시·군·구로 추출한다. 일반구가 있는 시는 시와 하위 구를 모두 제공한다. 세종은 별도 시·군·구 없이 선택한다.
- 원본 TXT SHA-256: `962fd4cdfb6ccf2887b745eb97db55f71112b9f9a32c1f8fbd7692fb069b1df0`.
- 추출 파일: `lib/korea-regions.json`. 16개 시·도와 268개 시·군·구 선택 항목. 목록은 다운로드 당시의 코드 기준이며, 행정구역 개편 시 같은 기준으로 갱신해야 한다.

지역 선택 시 외부 API 호출 없이 저장소의 정적 목록을 사용한다. 주소나 상품 입력값을 외부로 전송하지 않는다.
