# FRUIDAM Studio

상품 정보 입력 → 섹션 구성안 편집 → 상세페이지 디자인 → 다운로드 흐름으로 동작하는 상세페이지 제작 앱입니다. Next.js App Router + React + TypeScript를 사용하며 로컬에서 실행합니다. 작업 저장은 Supabase를 지원하고 로그인·배포 기능은 추가하지 않았습니다.

## 실행

Node.js 20.9 이상이 필요합니다.

```bash
npm install
npm run dev
```

http://localhost:3000 에서 접속합니다. 샘플 작업을 열거나 **샘플로 시작하기**로 전체 제작 흐름을 확인하세요. 샘플 이미지는 내장 상품 일러스트이며 실제 상품 사진으로 교체할 수 있습니다.

```bash
npm run lint
npm run build
npm start
```

`npm start`도 로컬 서버 실행입니다. 배포하지 않습니다.

## 제작 흐름

1. **상품 등록**: 1단계 상품 정보 → 2단계 디자인 기획안으로 나눈어 입력합니다. 상품명, 사진, 특징, 가격, 옵션 입력. 디자인 기획안, 참고 리뷰, 레퍼런스 이미지 추가. 6가지 컬러 테마, 스토리형/간결형 디자인 구성과 **15/25섹션** 길이 선택. 추천 대상과 배송·교환 안내 입력란은 제공하지 않습니다.
2. **구성안 편집**: 왼쪽 도구와 페이지 썸네일, 가운데 실제 상세페이지 캔버스, 오른쪽 속성 패널로 구성됩니다. 선택한 길이에 맞게 15개 또는 25개 섹션을 생성하고, 텍스트·사진·페이지 유형·전체 테마·레이아웃을 실시간 편집합니다. 페이지 검색, 드래그 정렬, 위아래 이동, 복제, 삭제, 숨기기, 실행 취소·다시 실행, 확대·축소를 지원합니다. 화면 하단의 **다음: 문구 검수**로 이어집니다. 기존 작업의 편집 내용과 섹션 수는 유지됩니다.
3. **문구 검수**: 섹션별 제목·본문을 수정하고 확인 완료 표시. 빈 문구, 긴 제목, 겹친 공백, 일부 단정 표현을 점검합니다. 공백 정리, 미확인/점검 항목 필터, 전체 확인 완료를 지원합니다. 문구를 바꾸면 해당 섹션은 다시 미확인으로 표시됩니다. 실제 맞춤법·사실 확인은 사용자가 수행합니다.
4. **편집기**: 왼쪽 섹션 목록, 가운데 860px 실시간 미리보기, 오른쪽 제목·본문·사진·테마 편집. 25~100% 배율 조절. 문구 검수 페이지로 돌아갈 수 있습니다.
5. **내보내기**: 가로 860px 긴 PNG 이미지 또는 사진을 포함한 독립형 HTML 다운로드. 숨긴 섹션과 편집 UI는 제외됩니다. PNG 생성 중에는 잠시 기다려주세요. 섹션이나 사진이 매우 많아 브라우저 메모리를 초과하면 HTML을 이용하세요.

## 디자인 기획안과 참고 자료

- 기획안은 최대 3,000자. TXT/MD 파일(2MB 이하)에서 불러올 수 있습니다. `메인 문구: ...`, `서브 문구: ...` 형식으로 적으면 새로 생성하는 히어로에 반영합니다. 생성 후 기획안 변경은 기존 문구를 덮어쓰지 않습니다.
- 참고 리뷰는 직접 입력하거나 TXT/CSV/XLSX(2MB 이하)에서 가져올 수 있습니다. XLSX는 앞 3개 시트의 각 200행·20열까지, 텍스트는 최대 12,000자까지 읽습니다. 첨부 문서는 텍스트와 파일명으로 보관되며 원본 파일을 별도로 저장하지 않습니다.
- 리뷰 스크린샷 1장, 레퍼런스 최대 10장. JPG/PNG/WebP/AVIF, 장당 8MB 이하. 기존 사진 업로드와 같은 방식으로 로컬에 저장합니다.
- 문구 검수 화면에서 기획안·리뷰·레퍼런스를 나란히 볼 수 있습니다. 리뷰와 레퍼런스는 참고용이며 완성본에 자동 삽입하지 않습니다. 스크린샷 OCR이나 레퍼런스 이미지 분석은 하지 않습니다.
- 기획안과 검수 상태도 현재 작업 저장소에 함께 저장됩니다. Supabase 연결과 이전 방법은 [Supabase 저장소 안내](docs/supabase.md)를 참고하세요. 기존 작업은 기획안 없이 그대로 열 수 있습니다.

작업 목록에는 검색, 정렬, 즐겨찾기, 복제, 삭제가 있습니다. 편집은 변경 후 약 0.65초 뒤 자동 저장하며, 화면 이동과 내보내기 전에도 저장합니다. 새로고침 전 헤더의 **저장됨** 표시를 확인하세요. 오류 발생 시 **다시 저장**으로 재시도할 수 있습니다.

구성안 오른쪽 하단의 고정 입력창에서 글과 음성으로 편집합니다. `제목: 새 제목`, `글씨를 48px로`, `사진을 오른쪽 20px 이동`, `사진 밝기 120` 등은 즉시 적용합니다. 명령이 아닌 일반 글은 선택한 텍스트에 적용합니다. AI 연결 시 자유로운 문구 작성·리뷰 보완 요청을 이해하고 자동 적용합니다. Enter로 적용하고 Shift+Enter로 줄바꿈합니다. 요청 중 변경된 문구는 이전 AI 응답으로 덮어쓰지 않습니다.

마이크 버튼은 브라우저의 한국어 음성 인식을 사용합니다. 인식 완료 후 자동 적용이 기본이며 체크를 끄면 전송 전 확인할 수 있습니다. 지원하는 Chrome/Edge 버전과 마이크 권한이 필요하며, 브라우저에 따라 음성이 외부 인식 서비스로 전송되고 네트워크가 필요할 수 있습니다.

### 자유 배치

- 드래그로 텍스트·사진 이동, Ctrl/Alt+드래그로 복사하며 이동, Shift+드래그로 수평/수직 이동.
- 같은 페이지에서 Shift+클릭으로 다중 선택. 정렬·간격 배분, 그룹(Ctrl+G)·해제(Ctrl+Shift+G), 잠금(Ctrl+2)·해제(Ctrl+Alt+2).
- 선택 상자의 모서리를 드래그해 사진·글자 크기 조절. 속성에서 회전 조절. 드래그 한 번은 한 번의 Ctrl+Z로 취소.
- 위치·그룹·잠금·복사한 요소는 로컬 저장과 내보내기에 반영됩니다.

### 생성 진행 화면·직접 편집·AI 작업

구성안 생성을 누르면 별도 진행 화면로 이동합니다. `/api/studio/create`가 NDJSON으로 상품 정보 확인·페이지 흐름 구성·카피 작성·저장 상태를 보내면 화면에 현재 작업과 경과 시간을 표시합니다. 완료하면 편집기로 이동하며 오류 시 입력값을 유지하고 재시도합니다. 같은 요청 ID로 재시도하면 저장된 작업을 재사용합니다.

텍스트를 더블클릭하면 캔버스 위에서 직접 수정합니다. Ctrl+Enter/포커스 이동으로 완료하고 Esc로 취소합니다. 선택 상자는 모서리 4곳과 변 중앙 4곳의 조절점을 제공합니다. 좌우 중앙은 텍스트 상자·사진 너비를, 상하 중앙은 글자 크기·사진 높이를 조절합니다.

AI 도우미는 선택 요소·다중 선택·섹션 내용을 이해하고 문구, 요소 추가/삭제, 글꼴/서식, 위치, 페이지 구성/순서, 테마를 수정합니다. 서버는 허용된 편집 작업·선택 범위·저장 형식을 확인한 후 적용합니다. `포인트를 4가지로 만들어줘`는 정확한 개수의 카피로 반영하며, **후킹 보완**은 쿠팡 공개 문구 검색을 요청하고 짧은 메인 문구와 상세한 2~3줄 설명을 작성합니다. 판매 순위를 확인하지 못하면 베스트셀러로 주장하지 않습니다. 음성 인식 중에는 마이크 파형·상태 표시가 움직입니다.

로컬 폰트는 노토 산스, 노토 세리프, 개구, 고운돋움, 고운바탕, 도현, 검은고딕, 주아, IBM 플렉스 9종입니다. 모두 SIL OFL 1.1 라이선스를 포함하며 `public/font-licenses/`에 원문이 있습니다. 변형하지 않은 폰트를 제공하고 상업적 제작물에도 사용할 수 있습니다. `/api/fonts`는 선택한 폰트와 라이선스를 HTML/PNG 내보내기에 포함합니다.

### 상품 입력 화면

상품 정보에서 이름·사진·카테고리·가격·특징·옵션을 입력한 뒤 디자인 기획안으로 이동합니다. 이전·다음으로 오가도 입력 내용을 유지합니다. 옵션은 한 줄씩 추가·삭제하고 체크한 줄만 구성안에 사용합니다. 옵션에서 Enter를 누르면 다음 줄을 추가합니다.

디자인 기획안에서 기획안·리뷰·레퍼런스·분위기·길이를 정합니다. **리뷰파일** 버튼 하나로 TXT/CSV/XLSX 문서나 JPG/PNG/WebP/AVIF 이미지를 선택합니다. 새 파일은 기존 리뷰 첨부를 대체합니다. 기존 3종 테마에 프레시 그린·로지 핑크·클리어 블루를 추가했습니다.

### 요소 선택과 디자인 도구

캔버스의 제목·서브 카피·본문·사진·추가 요소를 직접 클릭하면 선택 테두리가 나타나고, 해당 요소에 맞는 도구가 열립니다. 페이지 빈 영역을 클릭하면 페이지 전체를 선택합니다.

- **텍스트**: 메인/서브/본문 텍스트 추가, 스타일 프리셋, 상업적 사용이 가능한 OFL 한글 폰트 9종, 글자 크기, 굵게·기울임·밑줄, 색상, 정렬, 줄 간격, 자간. 폰트를 앱에 포함하며 HTML/PNG 다운로드에도 반영합니다.
- **사진**: 사진 선택·업로드, 높이·너비, 모서리, 채우기/전체 맞춤, 자르기 기준 위치, 밝기·대비·채도·불투명도, 좌우 반전. 원본을 수정하지 않고 렌더링 스타일로 적용합니다.
- **요소**: 텍스트, 둥근 배지, 원형 도장, 사각 카드, 구분선 추가. 추가 요소는 페이지당 최대 20개이며, 내용·색상·모양을 편집하거나 복제·삭제할 수 있습니다.
- **레이어**: 제목·서브·본문·사진과 추가 요소를 목록에서 선택합니다. 숨긴 요소도 다시 선택하고 표시할 수 있습니다.
- **구성/색상**: 페이지 유형, 여백 프리셋, 페이지 배경색, 전체 테마, 텍스트 포인트 색상 선택.

서식과 추가 요소는 로컬 작업에 함께 저장되고, 썸네일·미리보기·PNG·HTML에도 반영됩니다. 다운로드에는 선택 테두리와 편집 UI가 포함되지 않습니다. 추가한 문구와 배지도 문구 검수 페이지에서 확인·수정할 수 있습니다.

### 편집 단축키

구성안 편집기에서 `?`, `Ctrl + /`, `F1` 또는 상단 키보드 버튼으로 전체 안내를 엽니다. Mac에서는 Ctrl 대신 ⌘를 사용합니다.

| 키 | 동작 |
| --- | --- |
| Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z | 실행 취소 / 다시 실행 |
| Ctrl+C / Ctrl+X / Ctrl+V | 선택 요소·사진·페이지 복사 / 잘라내기 / 붙여넣기 |
| Ctrl+D / Delete | 선택 항목 복제 / 삭제 |
| Ctrl+Shift+C / Ctrl+Shift+V | 서식 복사 / 붙여넣기 |
| Ctrl+B / I / U | 굵게 / 기울임 / 밑줄 |
| Ctrl+Shift+L / E / R | 왼쪽 / 가운데 / 오른쪽 정렬 |
| Ctrl+Shift+> / < | 글자 크기 2px 확대 / 축소 |
| 방향키 / Shift+방향키 | 선택 요소 1px / 10px 이동 |
| Alt+↑/↓ 또는 Ctrl+[/] | 추가 요소나 페이지 순서 변경 |
| Ctrl+Shift+[/] | 맨 위 / 맨 아래로 이동 |
| Ctrl+Shift+H | 선택 항목 숨기기 / 표시 |
| Ctrl++/− 또는 Ctrl+휠 | 캔버스 확대 / 축소 |
| Ctrl+0 / Ctrl+1 | 화면 맞춤 / 100% 보기 |
| Ctrl+S / Ctrl+Alt+E | 저장 / 다운로드 창 |
| V / T / I / P / G / L / C | 페이지 / 텍스트 / 사진 / 구성 / 요소 / 레이어 / 색상 도구 |
| Esc | 요소 선택 해제, 안내 창 닫기 |

입력창의 복사·붙여넣기·실행 취소·삭제는 브라우저의 일반 텍스트 편집 동작을 유지합니다. 대화상자를 열면 캔버스 단축키는 적용하지 않습니다. 요소와 서식 복사는 편집기 내부 클립보드를 사용하며, 편집기를 떠나면 초기화됩니다. 내부 복사 항목이 없으면 외부 텍스트·이미지도 캔버스에 붙여넣을 수 있습니다. 이미지 파일은 기존 사진 업로드 용량·형식 제한을 적용합니다.

기본 제목·본문·사진의 Delete/잘라내기는 숨기기로 처리하고, 추가 요소와 페이지는 실제 삭제합니다. 숨긴 기본 요소는 레이어에서 다시 표시할 수 있습니다. 페이지 선택 상태의 일반 방향키는 이전·다음 페이지를 선택합니다. 위치 이동 값도 저장·다운로드에 반영됩니다. 실행 취소는 최근 60개 편집을 보관하며 새로고침하면 초기화됩니다.

## 생성 방식과 AI 연결

상단 **API 연결** → Gemini API 키 입력 → 설정 저장. 기본 모델은 `gemini-3.8-flash`이며 모델명을 변경할 수 있습니다. 선택적으로 `GEMINI_API_KEY`, `GEMINI_MODEL` (`GOOGLE_API_KEY`도 지원) 서버 환경변수를 사용합니다. Gemini generateContent API의 JSON schema로 섹션 id·개수·문구 형식을 확인한 뒤 적용합니다.

API 키는 `data/ai-settings.json`에 저장되고 설정 조회 응답에 반환되지 않습니다. 서버에서만 사용하며 Git에서 제외됩니다. AI 사용 시 상품 정보·기획안·리뷰 텍스트가 Google Gemini로 전송되고 API 요금이 발생합니다. 리뷰 스크린샷 OCR은 포함하지 않습니다. 사진 생성은 등록한 상품 이미지를 참고합니다.

새 상세페이지나 **전체 문구 작성**은 상품 특징·옵션·리뷰를 반영해 15/25섹션의 문구를 자동 작성합니다. Google 검색을 켜면 쿠팡 중심으로 같은 카테고리의 구성·구매 포인트를 참고하고 실제 검색 출처를 문구 검수에 표시합니다. 접근 차단된 페이지는 우회하지 않으며 확인하지 못한 판매 순위·베스트셀러를 주장하지 않습니다. 타사 문구를 복제하거나 근거 없는 인증·효능·후기를 만들지 않도록 지시합니다.

키가 없으면 제공한 상품 자료와 리뷰 키워드로 완성된 기본 문구를 만듭니다. 이 모드는 자유로운 AI 요청을 이해하지는 못합니다. 연결된 AI의 오류는 표시하며 조용히 기본 문구로 대체하지 않습니다.

### 연결 확인과 농사로 준비

Gemini 설정의 **설정 저장**은 키·모델 연결을 확인한 뒤 저장하고 창을 닫습니다. 확인에 실패하면 기존 설정을 유지하며 오류를 표시합니다. AI 사용을 끄거나 키를 제거하는 작업은 연결 확인 없이 적용합니다. 다시 열면 저장된 키를 마스킹하여 표시하고, 재입력 없이 재사용합니다. **키 변경**으로만 새 키를 넣습니다.

모델은 경제형·균형형·고급형 6개를 중복 없는 선택창으로 제공하며 다른 모델 ID도 직접 입력할 수 있습니다. 등급은 앱의 용도별 안내이며 실제 요금·권한은 Google 계정에 따릅니다.

**키·모델 연결 확인**은 Google의 모델 정보 API를 조회해 키와 `generateContent` 사용 가능 여부를 확인합니다. 문구는 생성하지 않으며 생성·검색 할당량까지 보증하지는 않습니다. `Gemini 3.8 Flash`처럼 입력해도 `gemini-3.8-flash`로 정규화합니다. 이전 OpenAI 키·모델은 Gemini 요청에 사용하지 않습니다.

**API 연결 → 농사로 공공데이터**에서 인증키·신청 서비스명·서비스 경로·활용 메모를 미리 저장합니다. `data/nongsaro-settings.json`에 별도 저장하며 `NONGSARO_API_KEY` 환경변수도 지원합니다. 현재는 **준비 단계**이며 실제 공공데이터 조회나 AI 문구 반영은 하지 않습니다. 공식 서비스 매뉴얼을 결정한 후 `lib/nongsaro.ts`에 요청 항목·XML/JSON 응답 분석·출처·이용 조건을 연결하면 됩니다. `/api/nongsaro`는 준비 상태와 빈 결과만 반환합니다.

### 상품 참고 사진로 새 연출컷 생성

디자인 기획안의 **사진 연출**에서 원본+AI 혼합 또는 원본만 사용을 선택합니다. 혼합 모드로 새 구성안을 만들면 대표·옵션 원본을 남겨 두고, 15섹션은 3장·25섹션은 4장의 산지·수확·선별·일상 연출컷을 순서대로 생성합니다. 성인 모델·손길 포함 여부와 촬영 느낌을 설정할 수 있습니다. 등록한 상품 사진 최대 2장을 기준으로 상품의 모습을 유지하도록 지시합니다.

기존 작업은 구성안 상단 **산지·모델컷 생성**을 누르거나, 사진 도구에서 장면·추가 요청을 골라 선택 페이지를 생성합니다. 글·음성 요청에서도 `이 페이지 사진을 자연스러운 수확 컷으로 만들어줘`처럼 요청할 수 있습니다. 원본은 보관하며 **생성 전 사진으로 되돌리기**로 복구합니다. 생성된 사진은 페이지와 다운로드에서 AI 연출 이미지로 표시됩니다. 실제 농장·생산자 촬영으로 주장하지 않습니다.

Gemini 설정에 **사진 생성 모델**이 별도로 있습니다. 기본 `gemini-nano-banana-2.1`, 선택 `gemini-3.1-flash-image`, `gemini-3-pro-image`. `/api/generate-image`은 서버에서 키와 로컬 상품 사진을 사용하고 결과를 WebP로 저장합니다. 사진와 섹션 문구가 Google로 전송되며 이미지 생성 요금·할당량이 적용됩니다. 키 미등록·한도 초과·응답 오류 시 원본과 완료된 결과를 유지하고 재시도할 수 있습니다. 생성 중 사용자가 사진·문구를 수정하면 이전 응답을 덮어쓰지 않습니다.

## 데이터와 사진

- Supabase 연결 시 `FRUIDAM_projects`·`FRUIDAM_sections`에 상품 정보·기획안·리뷰·검수·섹션·서식을 저장합니다. 상단에 `SUPABASE`가 표시됩니다. 서버 키는 Git 제외 `.env.local`에만 두며 브라우저에 전송하지 않습니다.
- `data/studio.json`: 로컬 모드의 상세페이지 작업과 섹션 정보. Supabase 이전 후에도 원본과 `data/backups/`를 남기며, 이후 클라우드 수정 내용이 이 파일에 자동 복제되지는 않습니다.
- `data/uploads/`: 업로드 사진. JPG/PNG/WebP/AVIF, 장당 8MB, 최대 10장. 서버에서 방향 보정, 크기 제한 후 WebP로 저장합니다.
- 사진·AI 설정 백업 시 `data` 폴더 전체를 복사하세요. 클라우드 작업은 Supabase DB에서도 별도로 백업합니다. `data/`와 실제 환경변수 파일은 Git에서 제외됩니다.
- 기존 투두 데이터가 있다면 `data/workspace.json`에 그대로 보관되어 있으며 새 앱에서 사용하지 않습니다.
- 작업 삭제 시 이미지 원본은 다른 작업에서 참조할 수 있어 유지됩니다.

같은 서버에 접속하는 브라우저는 같은 개인 작업실을 사용합니다. 로컬 모드는 쓰기 큐와 임시 파일 교체 방식이며, Supabase 모드는 변경 프로젝트만 트랜잭션·revision 검사로 저장합니다. 저장 요청 사이 충돌은 오류로 표시하며 자동 재시도나 자동 로컬 전환은 하지 않습니다. 이미 브라우저에 열려 있던 오래된 문서를 나중에 저장하면 그 문서가 현재 저장본을 대체할 수 있으므로, 여러 창의 문서 편집을 자동 병합하는 기능과는 다릅니다.

## 주요 파일

- `app/page.tsx`: 작업 목록, 입력 폼, 구성안, 편집기, 다운로드
- `components/detail-page.tsx`: 미리보기와 내보내기에 공통으로 쓰는 상세페이지 렌더러
- `components/outline-studio.tsx`: 도구 레일·페이지 썸네일·캔버스·편집 패널을 갖춘 구성안 편집기
- `app/api/studio/route.ts`: 생성·저장·즐겨찾기·복제·삭제 API
- `app/api/uploads/`: 업로드 이미지 검증·변환·조회
- `lib/studio.ts`: 데이터 타입, 테마, 상품 정보 → 섹션 구성 로직
- `lib/studio-store.ts`: 로컬/Supabase 저장소 선택과 쓰기 큐
- `lib/supabase-storage.ts`: 서버 전용 DB 접근·변경 비교·revision 검사
- `supabase/migrations/`: FRUIDAM 테이블·RLS·저장 함수
- `docs/supabase.md`: DB 연결과 데이터 이전 안내
